# Matriz de cumplimiento · Prácticas 4.1 y 4.2

[Enunciado 4.1](./Enunciado_Practica_4_1_IoT.txt) · [Enunciado 4.2](./ENUNCIADO_PRACTICA_4_2.txt) · [Repositorio](https://github.com/Jack28-08/control-iot-jack) · [Sitio GitHub Pages](https://jack28-08.github.io/control-iot-jack/)

La práctica 4.1 entregó Control. La 4.2 incorporó Monitoreo en el mismo sitio y conservó Control y Demo. La consola integrada mantiene ese alcance. Las referencias recuperables son `practica-4.2-entrega` (`fd3930e`) y `node01-redisenio-anterior` (`24d7321`). La práctica 4.1 también conserva su referencia `codex/respaldo-4-1-20261113`.

- **Local** se refiere a código, pruebas unitarias y capturas de Chromium del frontend servido por HTTP local. El arnés sustituye REST y WSS por dobles. `evidencias/definitivo/simulacion/browser-results.json` registra 36 comprobaciones de diseño (12 tamaños × 3 vistas), 22 escenarios, 19 capturas y cero POST reales. El manifiesto identifica los archivos de la corrida válida.
- **Real histórico** se refiere al 13 de noviembre de 2026 y a la versión académica 4.2 publicada. En aquella sesión se verificaron lecturas HTTPS y WSS reales. Las actas y capturas están en `evidencias/4.2/publicacion/`. Un intento de salud en la mañana agotó el plazo y otra sesión posterior registró HTTP 200. Ninguno de esos resultados acredita el estado actual.
- **Publicación estática** se refiere a HTML, CSS, JavaScript y favicon en GitHub Pages. La comprobación de esos recursos se registra por separado de la integración con AWS. Esta revisión definitiva usa dobles para REST y WSS y no realiza consultas nuevas a AWS, POST reales ni pruebas de actuador físico.
- **Pendiente** identifica una comprobación que todavía requiere teléfono físico, una sesión autorizada con el backend real, una herramienta específica o completar la evidencia institucional.

Las rutas de capturas y documentos son relativas a la raíz de la copia local. `evidencias/` y `entregables/` están excluidas de Git y Pages. Las pruebas de movimiento real deben hacerse bajo autorización y con operador presente. Mantener fuera de las capturas las claves y los encabezados de autorización.
